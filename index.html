Machine Learning Methodology

CineMatch AI uses a multi-layered hybrid recommendation pipeline:

  • TF-IDF Vectorizer: Analyzes genre and synopsis tokens.
  • SVD Matrix Factorization: 30 latent factors across ratings.
  • Bayesian Weighted Rating: Prevents low-vote bias.
  • Offline Client-Side NLP: Zero external latency or API keys.
